# Security Policy

## Supported Versions

Only the current major release line receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

If you are on 1.x, upgrade to 2.x before reporting issues with the old line.

## Reporting a Vulnerability

**Do not open a public issue for a security vulnerability.** Use GitHub's
private vulnerability reporting instead: go to the repository's **Security**
tab and click **Report a vulnerability**. This opens a private advisory that
only the maintainer can see.

jest-express is a single-maintainer, spare-time project. Realistic
expectations:

- You should receive an initial response within about two weeks.
- If the report is accepted, a fix is released in the next patch release of
  the supported line, and the advisory is published after the fix is out.
- If the report is declined (for example, it only affects test setups where
  mocks already have full trust), you will get an explanation of why.

Thanks for helping keep jest-express users safe.
